# Portal Organisasi Mahasiswa - Himpunan Mahasiswa

Mini project website profil organisasi mahasiswa untuk mempublikasikan program kerja, struktur kepengurusan, pendaftaran anggota baru, dan kotak aspirasi mahasiswa. Proyek ini dikerjakan sebagai **Final Assignment Weekly Meet Catalyst**.

2. **Arju Latif Nur Muhammad** (H1D026012) - ([@Von-Albert](https://github.com/Von-Albert)) - Section About (Visi-Misi) dan Main Content (Program Kerja).
3. **Fachri Akbar Ishardi** (H1D026010) - ([@Gancraft](https://github.com/Gancraft)) - Section Contact & Aspirasi, Footer, JavaScript DOM, dan Responsive Styling.

## Tujuan Project
- Menyediakan portal resmi terpusat untuk mahasiswa kampus.
- Mempermudah mahasiswa mengetahui agenda kegiatan dan proker organisasi.
- Menyediakan wadah online pengiriman aspirasi mahasiswa.

## Teknologi yang Digunakan
- **HTML5:** Struktur semantik halaman web.
- **CSS3:** Styling, Flexbox, CSS Grid, dan Media Query responsive.
- **JavaScript Dasar:** Interaksi pengiriman formulir aspirasi via DOM.
- **Git & GitHub:** Version control, collaborative branches, Issues, dan Pull Requests.

## Bagian / Section Website
1. **Home / Hero Section:** Logo, navigasi menu, tagline sambutan, dan tombol CTA.
2. **About / Profile:** Latar belakang organisasi beserta visi dan misi.
3. **Main Content (Program Kerja):** Kartu kegiatan unggulan (Seminar Karir, Bakti Sosial, Lomba Ilmiah).
4. **Contact & Footer:** Formulir kirim aspirasi mahasiswa interaktif dan tautan media sosial resmi.

## Cara Menjalankan Website Secara Lokal
1. Clone repositori ini:
   ```bash
   git clone https://github.com/Fami-dev/portal-organisasi-mahasiswa.git
   ```
2. Buka folder proyek di komputer Anda.
3. Buka file `index.html` menggunakan browser (Google Chrome, Edge, Firefox) atau klik kanan pilih **Open with Live Server** di VS Code.
